from src.services.empleado_service import EmpleadoService
from src.repositories.empleado_repository import EmpleadoRepository

# Inicialización de la capa de servicio con inyección de dependencias
repo = EmpleadoRepository()
service = EmpleadoService(empleado_repo=repo)

# Registro y cálculo automático de ficha técnica
nuevo_empleado = service.crear_empleado({
    "cedula": "V-20123456",
    "nombres": "María Elena",
    "apellidos": "Rodríguez Santos",
    "departamento": "Docencia e Investigación",
    "cargo": "Profesora Titular",
    "salario_base": 850.00
})

print(f"Empleado registrado: {nuevo_empleado.codigo} | Estado: ACTIVO")
from sqlalchemy import Column, Integer, String, Float, Date, Enum
from src.models.base import Base

class Empleado(Base):
    __tablename__ = "empleados"

    id = Column(Integer, primary_key=True, autoincrement=True)
    cedula = Column(String(20), unique=True, nullable=False, index=True)
    nombres = Column(String(100), nullable=False)
    apellidos = Column(String(100), nullable=False)
    cargo = Column(String(100), nullable=False)
    departamento = Column(String(100), nullable=False)
    salario_base = Column(Float, nullable=False, default=0.0)
    fecha_ingreso = Column(Date, nullable=False)

Capacidades del Sistema

Módulos Funcionales Completos

Diseñado para cubrir todo el ciclo de vida del personal administrativo, obrero y docente con precisión normativa.

👥

Gestión de Personal

Ficha integral del empleado con datos personales, laborales, bancarios, médicos y carga fotográfica de perfil.

📄

Gestión Documental

Digitalización de expedientes en PDF/imágenes con alertas preventivas de vencimiento y reportes de control.

📋

Incidencias y Permisos

Control de ausencias, permisos remunerados y reposos médicos con cálculo automático de días hábiles y flujo de aprobación.

💰

Nómina y Deducciones

Cálculo automatizado de pagos periódicos, retenciones legales (seguro, pensión, impuestos), bonos y recibos de pago.

📊

Generación de Reportes

Emisión en PDF de constancias oficiales, recibos de pago, planillas salariales y exportación completa a Excel (.xlsx) y CSV.

🔒

Seguridad y Auditoría

Cifrado de credenciales con PBKDF2, control de acceso basado en roles (RBAC), registro de auditoría y respaldo de bases de datos.

Ingeniería de Software

Arquitectura Limpia en Capas

Separación estricta de responsabilidades, alta cohesión y bajo acoplamiento para facilitar el mantenimiento y la extensibilidad.

CAPA 01
Presentación (GUI)
CustomTkinter, navegación modular, temas claro/oscuro y soporte de alta resolución.
CAPA 02
Servicios
Lógica de negocio pura: cálculos salariales, validaciones y orquestación de procesos.
CAPA 03
Repositorios
Abstracción de acceso a datos mediante el patrón Repository independiente del motor.
CAPA 04
Modelos ORM
Entidades relacionales declarativas con SQLAlchemy, tipos estrictos y relaciones.
CAPA 05
Persistencia
SQLite con transacciones ACID, registro de auditoría y respaldos automáticos.

Despliegue y Ejecución

Inicio Rápido

Configura el entorno de desarrollo y ejecuta la aplicación en tres sencillos pasos.

bash (comandos de inicio) 
# 1. Clonar el repositorio
git clone https://github.com/LiebeBlack/SDEP_CPP5.git
cd SDEP_CPP5

# 2. Crear y activar entorno virtual Python 3.10+
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
# source venv/bin/activate

# 3. Instalar requerimientos y ejecutar la suite de pruebas
pip install -r requirements.txt
pytest -v

# 4. Lanzar la aplicación
python -m src.gui.main_window
